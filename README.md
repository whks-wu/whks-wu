## Deutsch

Ich komme von der Sprache zur Software: nach einem Masterabschluss in Germanistik
studiere ich heute Computerlinguistik. Nebenbei führe ich ein kleines Studio für
Deutschunterricht — und die Software, mit der meine Lernenden und ich täglich
arbeiten, entwickle ich selbst.

Meine Projekte entstehen KI-gestützt, mit Coding Agents und LLMs. Gelernt habe ich
dabei vor allem zweierlei: Ein Coding Agent ist nur so gut wie die Spezifikation,
die man ihm gibt — und generierter Code muss gelesen, im Betrieb getestet und
refaktoriert werden, bevor man ihn auf Nutzende loslässt.

## English

I came to software through language: after a master's degree in German studies I now
study computational linguistics. Alongside my studies I run a small German-teaching
studio — and I build the software my learners and I use every day myself.

My projects are built with the help of coding agents and LLMs. Two things I have
learned from working this way: a coding agent is only as good as the specification
you give it, and generated code still has to be read, tested in production and
refactored before you put it in front of users.

### Selected projects

| Project | What it is |
| --- | --- |
| [german-lernwerkstatt](https://github.com/whks-wu/german-lernwerkstatt) | A classroom exercise tool with three exercise types and a visual editor that lets the question bank be maintained without writing a line of code. Plus several Python projects from teaching myself the language — from Tkinter desktop
apps to Flask applications that consume external APIs.
